# Dr. Prokopchuk - сайт приватного лікаря

Статичний сайт без збірки: чистий HTML, CSS і JavaScript. Головний файл `index.html` лежить у корені, тому сайт відкривається одразу.

## Що змінювати найчастіше

**Контакти** (телефон, пошта, Telegram, Viber, адреса): відкрийте файл `kontakty.js`, змініть текст між лапками. Зміни автоматично підставляються всюди: у шапку, форму, QR-коди, підвал.

**Фото**: у `kontakty.js`, у блоці `photos`, вставлено прямі посилання на ваші фото (перший екран, прийом, «Про лікаря», «Досвід»). Щоб змінити, замініть посилання між лапками. Або залиште `''` і завантажте файли `foto-1.jpg` ... `foto-4.jpg` у папку `foto` (деталі в `foto/README.txt`).

**Карта тіла**: фігури людей лежать у `assets/img` (вирізані з вашої картинки), точки розставлені за нею. Відео органів (необов'язково): файли `video/heart.mp4`, `video/lungs.mp4` та інші, список у `video/README.txt`. З відео занурення в тіло виглядає як живе, без відео показується намальована схема органу.

**Тексти секцій, ціни, квіз, тести, карта тіла**: у файлах `assets/js/` (на початку кожного файлу об'єкт `CONFIG`, біля параметрів коментар `/* ЗМІНИТИ */`).

## Публікація

GitHub Pages: завантажте весь вміст папки в репозиторій, потім Settings, Pages, Source: Deploy from a branch, Branch: main, папка / (root), Save.

Netlify: Add new site, Deploy manually, перетягніть цю папку (або Import an existing project і оберіть репозиторій, налаштування підтягнуться з `netlify.toml`).

## Примітки

- Шрифти (Google Fonts) і QR-коди (api.qrserver.com) завантажуються з інтернету.
- Форма запису без сервера: відкриває Telegram або Viber, а текст заявки копіюється в буфер обміну.
- Тести й карта тіла довідкові, не є діагнозом, про що сказано на сайті.
